# SimWatch

SimWatch — это симулятор жизни для ESP32 SmartWatch.

Игра работает в реальном времени.

Все параметры вычисляются по прошедшему времени, а не по таймерам.

Это означает:

- часы могут быть выключены;
- аккумулятор не расходуется на фоновую работу;
- после включения состояние сразу пересчитывается.

---

# Основная идея

Пользователь управляет своим персонажем.

Персонаж имеет характеристики.

Каждая характеристика изменяется самостоятельно.

Пользователь выполняет действия, которые влияют на характеристики.

# Основные сущности

## Stat

Любая характеристика.

Примеры:

- Голод
- Жажда
- Сон
- Настроение
- Деньги
- Опыт

Каждая характеристика имеет:

- имя
- текущее значение
- минимум
- максимум
- интервал изменения
- величину изменения
- включена/выключена

---

## Action

Любое действие пользователя.

Например:

Поесть

↓

Голод +30

↓

Настроение +5

↓

Деньги -10

---

## Goal

Долгосрочная цель.

Например:

Купить автомобиль

Стоимость

50000 $

После достижения пользователь получает награду.

---

## Rule

Связь между характеристиками.

Например:

если

Голод < 20

↓

Энергия уменьшается быстрее.

---

## Profile

Набор характеристик.

Например:

Студент

Инженер

Спортсмен

или пользовательский профиль.

---

# Реальное время

Для каждой характеристики хранится

lastUpdate

При запуске часов вычисляется

deltaTime

После чего рассчитываются изменения.

Поэтому таймеры не используются.

---

# Web

Через Wi-Fi пользователь сможет:

- добавлять характеристики;
- удалять характеристики;
- менять интервалы;
- менять скорость изменения;
- создавать действия;
- создавать цели;
- создавать профили;
- импортировать и экспортировать настройки.
