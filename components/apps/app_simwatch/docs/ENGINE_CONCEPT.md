# SimWatch Engine Concept

## Philosophy

The Engine never modifies objects directly.

Everything that happens inside the simulation is represented as an Effect.

The Engine is deterministic.

Given the same Profile and the same timestamps,
the result must always be identical.

---

# Fundamental Rule

Objects never modify each other.

Instead they create Effects.

Example

Activity

↓

Effect

↓

Queue

↓

Apply

↓

Stat Updated

---

# Effect

Effect is the atomic operation of the Engine.

Every change inside SimWatch is an Effect.

Examples

• Hunger -5

• Energy +10

• Money +250

• Experience +50

• Notification

• Unlock Goal

• Add Modifier

Nothing bypasses Effects.

---

# Sources of Effects

Effects can be generated by:

• Passive decay

• Activities

• Rules

• Goals

• Rewards

• Economy

• Random Events

• User actions

All of them are treated equally.

---

# Effect Queue

Effects are never applied immediately.

They are placed into the Effect Queue.

Example

Clock

↓

Passive Effects

↓

Activity Effects

↓

Rule Effects

↓

Reward Effects

↓

Queue

↓

Apply

↓

Finished

---

# Benefits

Because every change is an Effect, the Engine gains:

✔ deterministic simulation

✔ undo support

✔ history

✔ debugging

✔ replay

✔ synchronization

✔ statistics

without additional code.
